# 3 Free University Courses to Learn Electrical Engineering

A one page reference built from the TikTok photo post by @meris.veladzic, 16 October 2026 (the companion to the electronics carousel).

Live at https://ee.holm.team, behind Holm ID (edge SSO, Holm ID integration playbook Pattern A).

Contents:

- UT Austin, Embedded Systems: Shape The World (Microcontroller Input/Output), self paced on edX, free access to the content
- MIT 6.622, Power Electronics (Spring 2023), taught by Prof. David Perreault, free via MIT OpenCourseWare, 38 videos
- TU/e Eindhoven, RF and millimeter-Wave Circuit Design, on Coursera (included with Coursera Plus, so not free; the page says so plainly)
- An honest level check: beginner door, full university course, master level specialism
